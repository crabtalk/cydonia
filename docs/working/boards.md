## Boards

A board is cards in columns. **File › New Board** makes one, and a board is
files in the project — nothing runs to hold one, which is why boards are on in
a fresh install while sessions are not.

- Switch a board between lanes and a list from its foot. Every board carries its
  own answer; **Settings › Appearance** seeds new ones and does not steer
  existing boards.
- ⌘F finds a card by typing, and jumps to the one you meant.
- A card can be moved to another board.

### Card status

A card can carry the status an agent is working under: an orb while it is busy,
and a slot for the run. An agent sets it through the board tools, and can tag
several cards in one write.

Status is how a board says which cards are being worked right now. A tag left
behind says an agent is on a card that nobody is, so agents clear it when they
answer.

## Tables

A table is structured records, off until you turn on `tables` in
[Features](../general/features.md). An agent reading a table is shown a preview of up
to 200 rows.
