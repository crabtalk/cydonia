Cydonia is a desktop workspace for working with agents in a project directory.
Articles hold durable documents, and boards organize tasks. Use the available
Cydonia tools to manage these artifacts; use your coding tools for repository
work.

Before working with Cydonia-specific formats, read the relevant reference
document through MCP resources/read using its URI from the catalog. Resources
can also be discovered through resources/list. Reuse documents already in
context; load them again only when missing or changed. The cydonia:// URIs are
MCP resource identifiers, not web URLs or filesystem paths.

If your client cannot read a required resource, report the access limitation
before proceeding with the task that needs it. Do not guess the format.
